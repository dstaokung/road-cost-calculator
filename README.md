# Road Cost Calculator

เว็บเพจ HTML หน้าเดียว (ไม่ต้องมีเซิร์ฟเวอร์) รวมตารางราคากลางงานก่อสร้างทาง 3 ฉบับจากกรมบัญชีกลาง:

1. **ค่าดำเนินการและค่าเสื่อมราคา** (หนังสือด่วนที่สุด ที่ กค 0433.2/ว 475 ลงวันที่ 26 มิถุนายน 2569)
2. **ค่าขนส่งวัสดุก่อสร้าง** (หนังสือด่วนที่สุด ที่ กค 0433.2/ว 477 ลงวันที่ 26 มิถุนายน 2569)
3. **อัตราราคางานดิน** (งานก่อสร้างชลประทาน — เอกสารไม่มีหน้าปกแนบมา)

กรอกราคาน้ำมันดีเซลและเลือกชนิดรถบรรทุกที่ช่องเดียว (ใช้ร่วมกันทั้ง 3 เอกสาร) ระบบจะหาหน้าเอกสารต้นฉบับที่ตรงกับช่วงราคานั้นให้อัตโนมัติ ครอบคลุมช่วงราคาน้ำมัน 25.00–69.99 บาท/ลิตร (ทีละ 1.00 บาท รวม 45 ช่วง) แล้วพิมพ์ "หน้าแรกของเอกสาร" + "หน้าที่ใช้งาน" (หน้าเอกสารจริงจาก PDF ต้นฉบับ ไม่ใช่ตารางที่สร้างขึ้นใหม่) ได้ทีละเอกสารหรือพิมพ์รวมกันทั้ง 3 เอกสารในครั้งเดียว (เอกสารอัตราราคางานดินไม่มีหน้าปกในไฟล์ต้นฉบับ จึงพิมพ์เฉพาะหน้าที่ใช้งาน)

## การใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย หรือเข้าผ่าน GitHub Pages)

1. เลือกแท็บด้านบน: "ค่าดำเนินการและค่าเสื่อมราคา (ว 475)", "ค่าขนส่งวัสดุก่อสร้าง (ว 477)" หรือ "อัตราราคางานดิน" — ใช้ดูตารางบนหน้าจอ ไม่กระทบการพิมพ์
2. กรอกราคาน้ำมันดีเซลที่อำเภอเมืองในช่อง "ราคาน้ำมันดีเซล" และเลือก "ชนิดของรถบรรทุก" (6 ล้อ / 10 ล้อ / 10 ล้อและรถลากพ่วง — ใช้เฉพาะเอกสารค่าขนส่ง) ที่แถบด้านซ้าย — ราคาน้ำมันใช้ร่วมกันทั้ง 3 เอกสาร ไม่ขึ้นกับแท็บที่เปิดอยู่
3. ระบบจะโหลดหน้าเอกสารจริงของทั้ง 3 ฉบับที่ตรงกับช่วงราคา (และชนิดรถ) ไว้พร้อมพิมพ์เสมอ (ไม่แสดงตัวอย่างบนหน้าจอ จะเห็นตอนสั่งพิมพ์เท่านั้น)
4. กดปุ่มพิมพ์ที่ต้องการ: "ค่าดำเนินการและค่าเสื่อมราคา", "ค่าขนส่ง", "อัตราราคางานดิน" หรือ "พิมพ์ทั้ง 3 อย่าง" (พิมพ์ต่อกัน: หน้าแรก+หน้าที่ใช้งาน ว 475, หน้าแรก+หน้าที่ใช้งาน ว 477, ตามด้วยหน้าที่ใช้งานอัตราราคางานดิน — 7 หน้ารวม)
5. แท็บ ว 475 และแท็บอัตราราคางานดินมีส่วน "เรียกดูค่าต่างๆ ทั้งหมด" ด้านขวา ให้เลือกช่วงราคาน้ำมันใดก็ได้โดยตรงหรือค้นหารายการงานด้วยคำค้น — ส่วนนี้เป็นข้อมูลแปลงจากตารางไว้ดูสะดวกๆ เท่านั้น ไม่ใช่หน้าที่ใช้พิมพ์ ส่วนแท็บ ว 477 มีข้อมูลอ้างอิงสูตรคำนวณและตัวแปรสภาพผิวทางไว้ให้ พร้อมปุ่ม "ถอดตัวเลขจากหน้าที่เลือกด้วย OCR" สำหรับดูตารางอัตราตามระยะทาง (1–200 กม. + อัตราต่อกิโลเมตรสำหรับ 201–1,000 กม.) ของหน้าที่กำลังเลือกอยู่บนหน้าจอโดยไม่ต้องพิมพ์ก่อน

### เกี่ยวกับปุ่ม OCR ในแท็บ ว 477

เอกสาร ว 477 เป็น PDF ที่สแกนเป็นภาพทั้งฉบับ (ไม่มีข้อความให้ดึงโดยตรง) ปุ่มนี้จึงถอดตัวเลขจากภาพหน้าที่กำลังแสดงอยู่แบบเรียลไทม์ในเบราว์เซอร์ (ใช้ Tesseract.js ประมวลผลบนเครื่องผู้ใช้ ไม่ส่งข้อมูลออกไปที่ใด) ข้อควรทราบ:

- **ต้องเปิดผ่านเว็บ** (เช่น GitHub Pages หรือรันผ่าน local web server) — ถ้าเปิดไฟล์ `index.html` โดยตรง (double-click, `file://`) เบราว์เซอร์บางตัว (เช่น Chrome) จะบล็อกการอ่านภาพผ่าน canvas ปุ่มนี้จะใช้งานไม่ได้และแจ้งข้อความให้ทราบ
- ครั้งแรกที่กดจะโหลดเครื่องมือ OCR ผ่านอินเทอร์เน็ต (ไม่กี่ MB) และใช้เวลาอ่านตัวเลขทั้งหน้าประมาณ 15–40 วินาที
- **ตัวเลขที่ได้อาจคลาดเคลื่อนได้** จากการทดสอบพบว่าอ่านถูกประมาณ 90% ของแถวทั้งหมด (ตัวเลขผิดหลักเดียวเป็นอาการที่พบบ่อยที่สุด) จึงมีข้อความเตือนกำกับไว้เสมอ — ให้ใช้เป็นตัวช่วยดูค่าคร่าวๆ เท่านั้น หากต้องใช้อ้างอิงจริงให้ตรวจกับหน้าที่พิมพ์ (หน้าเอกสารจริงจาก PDF) เสมอ

## โครงสร้างไฟล์

- `index.html` — หน้าเว็บหลัก (UI, แท็บ, การคำนวณ, การพิมพ์)
- `data.js` — ข้อมูลตาราง ว 475 (`DEPR_DATA`) และอัตราราคางานดิน (`DIRT_DATA`) ทั้ง 45 ช่วงราคาน้ำมัน แปลงมาจากเอกสาร PDF ต้นฉบับ (ใช้สำหรับส่วนเรียกดูค่าต่างๆ บนหน้าจอเท่านั้น)
- `cover-page.jpg` — ภาพหน้าแรกของหนังสือกรมบัญชีกลาง ว 475
- `pages/p002.png` ... `pages/p091.png` — ภาพหน้าเอกสารจริงของ ว 475 แต่ละช่วงราคาน้ำมัน (หน้าละ 2 ไฟล์ต่อช่วงราคา)
- `cover-page-477.jpg` — ภาพหน้าแรกของหนังสือกรมบัญชีกลาง ว 477
- `pages477/p009.png` ... `pages477/p280.png` — ภาพหน้าเอกสารจริงของ ว 477 ครบทั้ง 3 ชนิดรถ × 45 ช่วงราคา (หน้าละ 2 ไฟล์ต่อช่วงราคา ต่อชนิดรถ)
- `pages_dirt/p001.png` ... `pages_dirt/p045.png` — ภาพหน้าเอกสารจริงของอัตราราคางานดิน แต่ละช่วงราคาน้ำมัน (หน้าละ 1 ไฟล์ต่อช่วงราคา ไม่มีหน้าปกแนบ)

ไฟล์ภาพทั้งหมดแปลงมาจาก PDF ต้นฉบับโดยตรง (ไม่ใช่ตารางที่พิมพ์ขึ้นใหม่) ใช้เป็นหน้าที่ใช้พิมพ์จริง

## การนำขึ้น GitHub Pages

Push โฟลเดอร์นี้ขึ้น repository แล้วเปิดใช้งาน GitHub Pages โดยชี้ไปที่ branch/โฟลเดอร์นี้ ก็จะเข้าถึงเครื่องมือผ่านลิงก์เว็บได้ทันที ไม่ต้องมี backend ใดๆ (repo มีขนาดรวมประมาณ 58 MB ส่วนใหญ่เป็นภาพหน้าเอกสารสำหรับพิมพ์)

## ที่มาของข้อมูล

- ตารางค่าดำเนินการและค่าเสื่อมราคา (`DEPR_DATA` ใน data.js) แปลงมาจากไฟล์ PDF "ตารางค่าดำเนินการและค่าเสื่อมราคา" (91 หน้า, ว 475) ที่แนบมากับหนังสือกรมบัญชีกลาง
- ตารางค่าขนส่งวัสดุก่อสร้าง (pages477/) เป็น PDF ต้นฉบับที่สแกนเป็นภาพทั้งฉบับ (280 หน้า, ว 477) จึงไม่มีการแปลงเป็นข้อความ ใช้ภาพหน้าเอกสารจริงโดยตรงเพื่อความถูกต้อง
- ตารางอัตราราคางานดิน (`DIRT_DATA` ใน data.js) แปลงมาจากไฟล์ PDF "อัตราราคางานดิน" (45 หน้า, งานก่อสร้างชลประทาน) ตัวเลขดึงจากข้อความในไฟล์โดยตรงและตรวจทานกับภาพหน้าเอกสารจริงแล้ว รายการ "ค่าระเบิดหิน" ไม่มีตัวเลขในเอกสารต้นฉบับ (มีแต่หมายเหตุอ้างอิงไปยังอัตราของงานปรับปรุงฐานราก) และบางช่วงราคา (51.00 บาท/ลิตรขึ้นไป) บางแถวมีเครื่องหมาย "-" แทนตัวเลขในคอลัมน์ฝนตกชุกตามเอกสารต้นฉบับจริง ไม่ใช่ข้อมูลที่ขาดหาย

หากพบตัวเลขที่ไม่ตรงกับเอกสารต้นฉบับ กรุณาตรวจสอบกับ PDF ต้นฉบับอีกครั้งก่อนนำไปใช้งานจริง
